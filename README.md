# 🎮 Infanto Games — Loja de Games Retro

Projeto desenvolvido em **HTML puro** como parte de um mini desafio de desenvolvimento web.

## 📋 Sobre o projeto

A **Infanto Games** é uma página promocional de uma loja fictícia especializada em **games e consoles retrô**. O objetivo do projeto é apresentar a loja de forma simples, organizada e funcional, utilizando os principais elementos do HTML.

## 🕹️ Conteúdo

A página apresenta:

* 🎮 Consoles clássicos
* 💰 Tabela de jogos e preços
* 🖼️ Imagem da loja
* 🔗 Link interno para os preços
* 🌐 Link externo para uma loja de games
* ✨ Textos com negrito e itálico

## 💻 Tecnologias utilizadas

* HTML5

## 📂 Estrutura

```text
Infanto-Games/
│

    └── logo0000.png
```

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html`.
3. Execute o arquivo em qualquer navegador.

## 🎯 Objetivo do desafio

Demonstrar conhecimentos básicos de **HTML**, incluindo títulos, parágrafos, listas, links, imagens e tabelas, mantendo o código simples e com menos de 50 linhas.
